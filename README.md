# Ustad AI – Urdu Voice Tutor

Ask any question by voice, text, or picture, and get a simple spoken explanation in Urdu,
followed by a quick quiz.

Built with FastAPI, Google Gemini (multimodal), edge-tts Urdu voices, and Docker.
